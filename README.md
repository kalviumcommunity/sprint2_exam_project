# 🎓 Exam Proctoring System – Frontend

This is the frontend of the Exam Proctoring System built using Angular. The system allows students to log in and take exams while enabling monitoring and secure exam flow.

---

## 🚀 Tech Stack

- Angular
- TypeScript
- HTML5
- CSS3
- Node.js
- Angular CLI

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/harini18122005/Sprint2-ExamProject.git


Go into project folder:

cd exam-proctoring-frontend

Install dependencies:

npm install
▶️ Run the project
ng serve
